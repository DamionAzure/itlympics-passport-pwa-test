Unverified stamps — offline scans

Accepted on trust because the attendee's phone was offline at the moment of scanning, so the code's signature was never checked against the booth secret (see index.html). Almost always legitimate — venue wifi drops happen — but worth a glance if a booth reports something odd, since this is the one path that skips signature verification entirely. Mark a row verified once you're satisfied it's fine; that just clears it from this list.
