Unverified stamps — offline scans

Accepted on trust because the attendee's phone was offline at the moment of scanning, so the code's signature was never checked against the booth secret. Almost always legitimate (venue wifi drops happen), but worth a glance if a booth reports something odd. Mark a row verified once you're satisfied; that just clears it from this list.

Roster import (CSV)

Columns: student_id, name, section. A header row is optional, and columns can be in any order if you include one. Existing Student IDs are updated, new ones added, and nothing is deleted. Rows that fail the same ID/name checks as registration are skipped and listed below.

Role management

Everyone starts as user. Promote to staff (booths, entrance, dashboard, testing) or admin (everything, including wiping data). They need to have logged in once already. Only admins can do this, and the database enforces it.
